# 成长小队 Growing Squad

一个家庭私有、离线优先的儿童成长陪伴产品。它不是考核孩子的打卡器，而是通过游戏、共同参与、自由选择和渐进退出，帮助孩子从“家长带着做”走向“自己愿意做、知道怎样做”。

当前已经落地的第一个模块是“晚间成长”：孩子完成睡前准备、照料花园、收藏成长纪念；家长通过服务端校验的 PIN 管理作息、流程和家庭数据。未来同一套角色、世界与成长记录将扩展到运动、阅读、整理、家务、亲子项目、情绪表达和探索学习。

## 长期产品原则

- 先让孩子觉得好玩、有选择，再逐步形成稳定节奏。
- 家长是早期脚手架，产品要帮助家长逐渐退出，而不是永久监督。
- 记录成长，不制造连续打卡、失败归零、羞耻或惩罚。
- 用家庭共同参与替代单向命令，让孩子感到自己是家庭的一员。
- 为真实生活目标设计；模块可以增加，但孩子每次只看到当下最需要做的事。

```bash
npm run lint
npm test
npm run test:e2e
npm run test:pwa
npm audit
```

E2E 会自动启动本地 Vite 服务，覆盖首次设置、完整睡前流程、刷新持久化、多孩子切换与数据隔离、不限量任务分组、星星与愿望、家长 PIN、全部管理页面、备份和 390px 移动端一屏布局。PWA 测试会使用生产构建断网重载，验证应用壳与主插画可离线打开。

## 产品约束

- 按提前完成任务的分钟数获得对应星光；晚于计划时间完成不奖励也不扣分，花园仍会开花。
- 不使用怪兽、惩罚、连续打卡或失败归零；跳过任务不会责备孩子。
- 孩子申请愿望时不扣星，只有家长批准时扣除；批准后 30 秒内可撤销。
- 作息调整可选择今晚或下一晚生效；今晚临时调整会明确展示结算时间。
- 家长解锁只保留在当前页面会话；刷新或重新打开后需要再次输入 PIN。
- 支持多个孩子：每个孩子的作息、流程、星星、兑换申请、睡前记录和无障碍设置独立，愿望单为全家共享。
- 睡前任务支持一屏展示最多 16 项，完成与误点撤销都只需点按任务卡片。
- 孩子区的“今晚、花园、愿望”主页面在桌面和移动 Web 端均按一屏交互设计，不需要上下滑动。
- 云端使用 SQLite 保存权威数据；浏览器保留离线副本和动作队列，联网后按操作号去重同步。仍支持最近 7 份本地备份和 JSON 导入/导出。
- 家庭守护中心把“本机保存、云端同步、每日备份、备份校验”显示为一条可验证路径；只有确实存在可恢复副本时才显示全部安全，永久删除需在线重新验证家长 PIN。

## 家庭云端

- `server/server.mjs`：同源 API、SQLite WAL、孩子/家长权限、操作去重、推送调度和每日备份。
- `deploy/bedtime-cloud.service`：独立 systemd 服务，不依赖或重启同机其他应用。
- `deploy/Caddyfile.site`：旧公网 IP 入口跳转到正式子路径。
- `deploy/Caddyfile.bailey-route`：将静态资源、SPA 回退、`/api/cloud/*` 与专属终端 `/api/v2/*`、PWA 全部限制在 `bailey.baicells.com/bedtime/` 下，不占用 Bailey 根路径。
- `npm run migrate:cloud -- --input <v5.json> --output <v6.json> --bed-time 21:54`：生成并校验云端种子数据。
- iPad 首次输入家庭连接码；之后从主屏幕打开会直接进入孩子模式。家长设置由短时家长会话授权。

## 代码结构

- `src/domain/model.js`：v5 多孩子领域模型、提前分钟星光、永久奖励收藏和 reducer。
- `src/data/storage.js`：校验、迁移、持久化、备份、导入导出和 PIN 哈希。
- `src/pages`：儿童端、首次设置、家长门禁和家长工作台页面。
- `src/layouts`：儿童与家长两套信息架构。
- `src/store`：应用状态、即时保存与页面离开兜底保存。
- `tests/e2e`：真实 Chromium 用户链路测试。
- `tests/production`：生产构建与离线可用性测试。
