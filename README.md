# 成长小队 Growing Squad

一个家庭私有、离线优先的儿童成长陪伴产品。它不是考核孩子的打卡器，而是通过游戏、共同参与、自由选择和渐进退出，帮助孩子从“家长带着做”走向“自己愿意做、知道怎样做”。

当前已实现日间小行动、晚间成长、运动小队、阅读桥梁、家庭责任、发明家工坊，以及统一的真实成长记录和家长观察。孩子端保留“今天 / 小队世界 / 成长背包”三个主入口；家长端负责计划、帮助回应、资料与数据管理。

## 本轮功能与交互更新

| 场景 | 已实现的行为 |
| --- | --- |
| 今天的小行动 | 最多二选一，开始、完成、休息、提前恢复、跳过；按孩子、日期和流程隔离，旧记录保留。 |
| 真实成长 | 只聚合实际记录；没有历史就显示空状态；家庭活动分别记录个人角色和共同完成，不作姐妹排名。 |
| 阅读桥梁 | 三种常用线下读法优先，其他方式按需展开；可选感受与笔记，区分孩子原话和家长观察；家长可以回看。 |
| 运动小队 | 选择后离开屏幕去玩，回来反馈；最新反馈影响下次推荐；主动性来自家长明确观察，不来自页面点击。 |
| 发明家工坊 | 洗头机器人、书包保护罩、专注小助手分别有自己的测试和线索，支持自定义想法、原型附件和再次迭代。 |
| 家长支持 | 回应求助、记录实际陪伴方式、手动确认支持调整；缺少观察时保持“不确定”，不自动降级帮助。 |
| 前端体验 | 延续毛毡与纸艺资产，扩大触控目标，清楚呈现选中/进行中/完成状态；支持键盘焦点、减少动画和窄屏自然滚动。 |

实施范围、数据兼容与验收方法见 [本轮交付说明](docs/trustworthy-growth-release.md)。

## 长期产品原则

- 先让孩子觉得好玩、有选择，再逐步形成稳定节奏。
- 家长是早期脚手架，产品要帮助家长逐渐退出，而不是永久监督。
- 记录成长，不制造连续打卡、失败归零、羞耻或惩罚。
- 用家庭共同参与替代单向命令，让孩子感到自己是家庭的一员。
- 为真实生活目标设计；模块可以增加，但孩子每次只看到当下最需要做的事。

## 本地运行

使用 Node.js 22；依赖版本以 `package-lock.json` 为准。

```bash
npm ci
npm run dev
```

本地入口为 `http://127.0.0.1:5173/bedtime/`；生产入口为 `https://bailey.baicells.com/bedtime/`。

生产构建与预览：

```bash
npm run build
npm run preview
```

## 验证

```bash
npm run lint
npm test
npx playwright install --with-deps chromium
npm run test:e2e
npm run test:pwa
npm audit
```

E2E 自动启动本地 Vite，使用独立浏览器上下文和测试数据，覆盖睡前结算、愿望审批/撤销、PIN、多孩子隔离、日间流程、阅读原话、运动反馈、发明与附件、求助回应、备份等真实用户操作。包含 320px 大字模式、390px 手机、1194px 平板和 1440px 桌面视口检查；这些是 Chromium 自动化检查，不代表真机 Safari 验收。

GitHub Actions 在 Linux 上执行 lint、构建、单元/集成测试、完整浏览器回归和 PWA 生产离线检查。E2E 与 PWA 使用不同输出目录，浏览器截图和 trace 在 PWA 执行前保存，防止证据被清理。具体通过数量以对应提交的 Actions 结果为准，不能用旧提交的结果代替。

- `test-results/e2e-summary.json`：浏览器结构化结果。
- `playwright-report/e2e/`：可浏览测试报告。
- `artifacts/visual-qa/`：实际页面截图。
- `test-results/pwa-summary.json`：生产应用壳与主插画的离线重载结果。

## 产品约束

- 按提前完成任务的分钟数获得对应星光；晚于计划时间完成不奖励也不扣分，花园仍会开花。
- 不使用怪兽、惩罚、连续打卡或失败归零；跳过任务不会责备孩子。
- 孩子申请愿望时不扣星，只有家长批准时扣除；批准后 30 秒内可撤销。
- 作息调整可选择今晚或下一晚生效；今晚临时调整会明确展示结算时间。
- 家长解锁只保留在当前页面会话；刷新或重新打开后需要再次输入 PIN。
- 支持多个孩子：每个孩子的作息、流程、星星、兑换申请、睡前记录和无障碍设置独立，愿望单为全家共享。
- 睡前任务在目标平板视口支持一屏展示最多 16 项；超过上限的历史数据不截断。完成与误点撤销只需点按任务卡片。
- 默认睡前流程包含“滴眼药水”“清洗鼻子”和“泡脚”；现有家庭在升级时会幂等补齐，不覆盖原有任务、顺序和历史记录。
- 手机、窄屏和大号文字优先保证可读、可点击；允许自然滚动，不为了“一屏”裁掉内容或压小按钮。
- 云端使用 SQLite 保存权威数据；浏览器保留离线副本和动作队列，联网后按操作号去重同步。仍支持最近 7 份本地备份和 JSON 导入/导出。
- 家庭守护中心把“本机保存、云端同步、每日备份、备份校验”显示为一条可验证路径；只有确实存在可恢复副本时才显示全部安全，永久删除需在线重新验证家长 PIN。

## 家庭云端

- `server/server.mjs`：同源 API、SQLite WAL、孩子/家长权限、操作去重、推送调度和每日备份。
- `deploy/bedtime-cloud.service`：独立 systemd 服务，不依赖或重启同机其他应用。
- `deploy/Caddyfile.site`：旧公网 IP 入口跳转到正式子路径。
- `deploy/Caddyfile.bailey-route`：将静态资源、SPA 回退、`/api/cloud/*` 与专属终端 `/api/v2/*`、PWA 全部限制在 `bailey.baicells.com/bedtime/` 下，不占用 Bailey 根路径。
- `npm run migrate:cloud -- --input <v5.json> --output <v6.json> --bed-time 21:54`：生成并校验云端种子数据。
- iPad 首次输入家庭连接码；之后从主屏幕打开会直接进入孩子模式。家长设置由短时家长会话授权。

## 代码结构

- `src/domain/model.js` / `src/domain/v7.js`：v7 领域状态、兼容迁移、睡前时间与奖励规则。
- `src/core`：日间决策、活动聚合、支持证据、设备与同步协议。
- `src/modules`：运动、阅读、家庭责任、发明、助手等模块 reducer 与数据模型。
- `src/data/storage.js`：校验、迁移、持久化、备份、导入导出和 PIN 哈希。
- `src/pages`：儿童端、首次设置、家长门禁和家长工作台页面。
- `src/layouts`：儿童与家长两套信息架构。
- `src/store`：应用状态、即时保存与页面离开兜底保存。
- `tests/e2e`：真实 Chromium 用户链路测试。
- `tests/production`：生产构建与离线可用性测试。
