# 成长小队音频素材

晚安页包含四首 5 分钟播放版：

- `bedtime-5min/wind-song.m4a`：风之歌，来自用户提供的 `M500002Qg6c21JLso5.mp3`（内嵌作者：水）。
- `bedtime-5min/you.m4a`：You，来自用户提供的 `M5000013DWrX0KMuwR.mp3`（内嵌作者：寒蝉鸣泣之时）。
- `bedtime-5min/moonflower-piano.m4a`：Forget Me Not，Kistol，https://opengameart.org/content/forget-me-not
- `bedtime-5min/rainy-dream.m4a`：Rizy's Sleep Music，Rizy，https://opengameart.org/content/rizys-sleep-music

用户提供的两首 MP3 被转为适合 Safari/iPad 播放的 AAC/M4A，并保留为 5 分钟版本。
每首文件包含 0.32 增益、2.2 秒渐入、8 秒渐出和循环接缝交叉淡化；播放不依赖网页定时器。

界面操作音效由应用使用 Web Audio API 实时合成，不使用第三方采样。
