# 成长小队 v4 · 一天的小路

v3 只是给旧结构换了皮：孩子端仍是「今天 / 世界地图 / 背包」三栏加 7 个地点，睡前仍是一次摊开 16 张卡，
家长端仍是 18 项侧栏，其中多数页面是旧页面套了新样式。v4 从使用场景重新出发，只保留数据与业务规则层
（`src/domain`、`src/modules/*/…Model/Reducer`、`src/core`、`src/store`），界面与交互全部重写在 `src/v4/`。

## 使用场景

- 4–6 岁：多数不识字。每个动作都要有图 + 可朗读；一屏只做一个决定；点按目标 ≥ 72px；不用滑动手势。
- 7–9 岁：能读，想要自主选择与收集感。
- 家长：在晚上最忙的几分钟里看一眼；要的是「现在怎样、要我回应什么」，配置很少改。

## 孩子端：以「此刻」为中心

旧版让孩子自己在地图、背包、花园之间找路。v4 让时间来带路：打开就是现在该做的一件事。

| 屏 | 作用 | 交互要点 |
| --- | --- | --- |
| 此刻 `/today` | 按一天的时间段自动切换：早晨 / 放学后 / 晚间成长 / 睡前小路 / 自由时间 / 已晚安 | 一张焦点卡 + 一个主按钮；下方至多 3 个「我还可以」入口（去玩、小伙伴、宝盒） |
| 睡前小路 `/tonight` | 一次只看一件事：大图、名字、朗读、「做好了」 | 小路上的石头显示全部进度，可点任意一块跳过去；做好后星光飞进罐子并自动走到下一件；误点有 5 秒「撤销」；「今晚不做」是低强调的次要动作 |
| 浇花 → 晚安 | 仪式感收尾 | 不可误触跳过，但可以「直接去睡觉」 |
| 去玩 `/play` | 4 扇大门：动一动、读故事、帮家里、小发明；另有愿望 | 每个门显示「上次玩到哪」 |
| 活动流程 | 统一的「步骤画框」：左上关闭、顶部步骤点、大图、底部一个主按钮 + 一个次要按钮 | 所有流程随时可以「先放一放」，回来能接着做 |
| 宝盒 `/box` | 花园（7 晚月亮花）、回忆（真实发生的事）、愿望（星光兑换） | 分段切换，不再分散在三个地点 |
| 小伙伴 `/pet` | 小屋 + 四个动作：照顾、一起玩、布置、相册 | 复杂功能收进底部抽屉，小屋常驻 |
| 家长入口 | 右上角小锁：**长按 1.5 秒**才出现 PIN | 防止孩子误入；键盘回车直接进入以保证可达性 |

视觉：「晨昏绘本」。背景与色调跟随时段变化（晨桃、日青、暮杏、夜靛），毛毡插画保留；UI 不再用缝线边框，
改用厚底「绘本贴片」按钮（按下会下沉），大圆角、强对比、少文字。

## 家长端：4 个区，不再有 18 项侧栏

| 区 | 内容 |
| --- | --- |
| 此刻 | 每个孩子今晚的实时进度；「待你回应」收件箱（求助、愿望、伙伴成长申请、角色调换、补记入睡）；快捷动作（记一句鼓励、临时调整今晚、补记入睡） |
| 成长 | 本周叙事周报、真实回忆时间线、陪伴程度（支架）、各活动的观察 |
| 安排 | 作息与提醒、睡前清单、一天安排、星光与愿望、伙伴规则、家庭角色、家庭书架、运动偏好、成长助手 |
| 家庭 | 孩子资料、显示与声音、设备与同步、备份与数据、家长 PIN |

每个区是一列可扫读的卡片，卡片进入单独的编辑页；桌面左侧窄栏、手机底部 4 个标签。

## 实施顺序

1. v4 基础：设计令牌、时段主题、通用组件（贴片按钮、底部抽屉、提示条、步骤画框、长按按钮）
2. 孩子端：此刻、睡前小路、浇花与晚安、去玩、宝盒
3. 活动流程：运动、阅读、家庭角色、发明、愿望、小问题、小伙伴
4. 入口：欢迎、设置、配对、家长 PIN
5. 家长端 4 区与全部编辑页
6. 删除 v3 与旧页面、旧样式；重写端到端测试；全量测试后统一部署
