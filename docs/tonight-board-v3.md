# 今晚任务 · 右侧清单改版（方案 3 精简版）

## 本次约束

延用 `feat/trustworthy-growth-comfort`。只改今晚任务页右侧，左侧插画、时钟、页面左右比例、顶栏与底部导航不重做。方案 3 原来占整行的第一项是“下一项”提示，本版取消它；所有任务平级，无推荐顺序，不因完成而重排。

## 已实现

- 删除“总清单 / 专注一件”整条切换栏，不再保留专注视图入口。
- 顶部只有紧凑标题、真实完成数和细进度条、临时调整按钮；没有占高的副标题或独立工具栏。
- 宽屏三列等宽横向图文卡；中等屏幕两列，窄手机一列。不牺牲完整名称来硬塞三列。
- 明确布局实际 `AssetArt` 的 span，而非只给不存在的 img 设置尺寸。名称正常换行、不限两行、不省略；旧数据超长时由内容撑高卡片。
- 在具有固定高度的桌面／横屏平板中，由右侧中间区域独立滚动，底部原结算按钮仍在右侧末行，不覆盖任务。低屏和手机保留自然页面滚动。
- 完成态用勾选和底色双重指示；跳过使用虚线与文字，不算成“已完成”。键盘 Enter/Space、撤销、临时跳过／恢复、刷新持久化沿用原操作。
- 保留原始名称、ID、顺序与结算，不添加效果图中的虚构任务、医疗建议或额外积分。

`src/ui/bedtime/TonightTaskBoard.jsx` 与 `tonight-task-board.css` 负责右侧。
