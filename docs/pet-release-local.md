## 已接通的体验

### 一、孵化与长期保留

每位孩子拥有一只伙伴。森林蛋固定孵出眠眠熊，月光蛋孵出月兔，云朵蛋孵出云朵，太空蛋孵出太空猫。领养前可预览，不随机抽取、不消耗星光。领养、取名、三种问候、裂纹变化、手动破壳与重播都有真实保存。

三种不同问候加至少两分钟，或者领养六小时后即可准备破壳，不必守着页面。出生由孩子亲自开启，晚些回来不会错过。已领养的宠物不因缺席死亡、逃跑、退化或扣亲密度。

孵化场景由上下蛋壳、对应幼崽、短暂柔光与有限动作组成；减少动态时直接展示结果。成长为幼崽、小伙伴、大伙伴，头身比例和手脚尺寸分别绘制，不是仅将同一张图片放大。家长可以保留幼崽外形而不影响本领。

### 二、角色动作和生活

四只伙伴分别有稳定的外形、耳朵/尾巴/帽子/脸部特征。头、身体、手脚、耳朵、尾巴、嘴、服装和手持道具分层表达。喂食会抱起点心并咀嚼；喝水有杯子动作；走动有交替步伐；抚摸、梳毛、泡泡澡、睡眠和庆祝有对应反馈。

房间停留时偶尔看窗外、伸懒腰；有明确偏好或学会本领后，才能出现推来喜欢的球、主动挥手、自己收玩具等行为。偏好来自不同日期的实际选择，同一天反复点击不增加偏好次数。不据此推断孩子的人格。

自主动作不循环不停播；隐藏页面、睡觉、安静时间、输入文字、打开弹窗、进行游戏、减少动态时暂停。触摸可以反复回应，但不反复刷成长。

玩过滚球/野餐等会产生少量泥点，梳毛或洗澡可以恢复；缺席不会累积泥点或健康压力。免费食物、喝水、梳毛、洗澡、睡觉一直可用。

### 三、真正可保存的玩法

- 滚球：可选择左右中三条方向，球和伙伴有不同的响应轨迹；没有手速评分。
- 找找看：三个小窝与提示，错误选择不扣分。
- 自由积木：6×4 格，四色、方块/屋顶/圆形，可以旋转、移走、撤销、命名、保存。
- 机器人试验场：轮子、挡板、速度和附加零件影响可见结果。小轮子可能卡台阶，低挡板且快车会掉球；调整后可重新实验，失败也能保存。
- 小剧场：选择森林/月光/太空背景，最多六个动作，可调整顺序、移除、演出、停止、保存和重播。
- 画给伙伴：有限笔画画布，颜色、撤销、命名、保存；也有无需精细拖动的贴小山操作。
- 三段可选择的小故事仍保留，并明确标识想象故事，不变成真实阅读或运动完成。

挥手、转圈、收玩具本领有不同练习程度。先试、逐渐熟练、学会后的动作不同；购买道具只开放练习，不直接升级。

普通小游戏每轮最多一分钟；积木、机器人、小剧场、画画最多三分钟。创作期间保存草稿；正常返回、切到后台或到达约定时保留已有作品。刷新可恢复正在进行的创作草稿；已完成作品可以继续作为新一轮的起点。切后台不继续计无限游戏时间。

### 四、星光养成

复用现有奖励账本，不增加第二货币，不让宠物小游戏产星光。15 件永久物件与玩法，固定价格 3—25 星光，包括装饰、衣服、积木、技能道具、故事与房间。

申请不扣星；家长批准或在允许的自主额度内兑换时才扣。服务端重新核对固定价格、余额和归属；重复请求、批准和退款不重复计账。批准后 30 秒家长可撤销，返还星光并收回道具相关摆放。

可以免费记下一个“我想慢慢攒”的目标，看到还差多少，随时改变目标。选目标不下单、不预扣、不发星，不用倒计时诱导。宠物消费与现实愿望共用余额，家长界面明确说明。

### 五、小屋、家庭花园和回忆

三种主题小屋保留。物件可用点选/拖动或方向按钮调整位置，保存后回小屋和刷新都保留。当前仍采用地毯、灯、装饰、玩具、装扮等类别位置：不是无限放置任意多件家具的建造游戏。

衣服在角色上有实际形状变化；基础床、饭碗、玩具可移动，床能触发休息，帐篷能进入找找看，灯能开关。相框可通向回忆。

家庭花园里每位孩子布置自己的花圃，选花、颜色、位置和留言；另一位之后进入也能继续布置自己的部分，不会伪造另一人的参与或修改对方花圃。不是多人实时联机游戏。

小屋纪念画保存当时的名字、房间、成长阶段、穿戴和布局；以后改名换装不会改变旧纪念画。明确称为“纪念画”，不是实际屏幕截图或现实照片。

作品柜和相册可保存绘画、积木、机器人和小剧场，支持命名、回看、挂墙、家长删除和导出。现实记录只引用已有事实，不重复发星或增加真实完成次数。

### 六、可选照片和语音

默认关闭。家长主动开启后，孩子可以选择图片或已有音频，也可以点击麦克风录制最多 30 秒。第一次必须由设备许可；先试听，确认后保存；取消、隐藏、卸载和迟到的许可结果都会释放麦克风。

不持续监听，不识别语音，不评分，不上传外部 AI。联网同步只走原家庭服务。每份最多 12MB，支持 PNG/JPEG/WebP 和指定常用音频格式；不接收 SVG、HTML、视频或任意执行内容。

服务端校验宠物/孩子归属、家长允许状态、已保存的媒体元数据、长度和基本文件签名。媒体 ID 不可替换成另一份内容，已撤销的设备不能继续以旧家长会话访问。签名校验不是完整病毒扫描或所有编码格式解码验证。

保存提示区分本机与云端。照片/语音先持久化原始内容，不能安全保存时明确报错；网络失败不删除本机原件。伙伴资料导出包含实际媒体及 SHA-256，不静默漏掉无法取得的媒体。

普通 JSON 备份不含媒体本体。伙伴 ZIP 是便于珍藏的资料包，不替代完整家庭恢复；恢复请沿用数据与安全中的家庭备份机制。

### 七、家长边界

可设置星光审批/自主额度、每天回合上限、每天玩耍和创作分钟数、安静时段、简易模式、保留幼崽、媒体许可。分钟数只计小游戏及创作回合，**不计所有应用使用、相册回看、基础照顾或花园布置**；不冒充系统级屏幕时长控制。

声音关闭和减少动态均保留。点读只选择设备已有的本地中文语音，没有可用语音时明示文字回退。四种角色有短合成回应音，不是动物录音或自由聊天系统。

## 图像交付

`PetCreature.jsx`、`pet-creature.css`、`PetArt.jsx` 是可维护的正式矢量资源。另附离线素材预览及 302 个独立 SVG：四角色×三年龄×二十状态/动作 = 240；练习阶段24；蛋状态12；独立道具26。SVG 内嵌有限时长样式，无外链图片、无字体文件、无执行脚本。

导出命令：

```bash
node scripts/export-pet-art.mjs
```

输出到被 Git 忽略的 `artifacts/pet-art/`。运行中的应用直接复用组件，并不会加载 302 份重复资源。素材不是先前的海报切图，不是逐帧视频；没有声称具备每个方向的写实动画或与生图效果一模一样的毛绒材质。
