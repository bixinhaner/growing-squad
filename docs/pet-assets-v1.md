# 小伙伴图像与动作清单

## 可运行资源，而非素材海报

角色沿用 `public/assets/companions/{bear,rabbit,cloud,space-cat}-poses-v1.webp`，每种六姿态，服饰/比例/面部以现有图集为准。六姿态为打招呼、安静抱抱、浇水、庆祝、睡眠、花园。背景沿用 `public/assets/themes/{moon-room,forest,space}-world-v1.webp`。不新增来源不明素材、图片热链、远程字体或跟踪脚本。

`src/ui/pets/PetArt.jsx` 是独立可复用的图像资源库。四颗蛋分别使用叶子、月牙、云与星球主题，带默认/一道裂纹/多道裂纹；角色固定对应而非随机。每颗蛋有单独的柔光色与纹样，不把小熊误变成小鸡。

无文字道具：蛋、球、食物碗、水杯、梳子、毯子、地毯、星灯、花盆、相框、围巾、雨衣、积木、丝带、收纳篮、野餐篮、帐篷、纸箱机器人、书本、森林、星球、旋律、星光、爱心。图形可放大、可独立调用；背景、角色、道具、文字和状态彼此分离。

## 已接入动作

| 场景 | 素材及变化 | 触发/结束 |
| --- | --- | --- |
| 蛋的问候 | 主题蛋轻晃、暖光、裂纹变化 | 主动点按；短反馈后停止 |
| 破壳 | 裂壳前景离开、同种幼崽出现、少量星光 | 孵化条件满足后点开；可随时关闭或重看 |
| 摸摸头 | 亲昵姿态、轻倾斜、小爱心 | 点伙伴；不刷成长 |
| 吃饭/喝水/梳毛 | 对应独立道具出现、安静姿态回应 | 免费照顾动作；短反馈收尾 |
| 走过来 | 角色走位、小幅步伐 | 三个地面位置可点；不是只靠拖拽 |
| 滚球 | 独立球滚出/回来、伙伴跳跃回应 | 一轮三次，最多一分钟 |
| 找找看 | 三个独立小窝、露出伙伴 | 错误位置给方向提示，不扣分 |
| 积木 | 孩子选色叠放、伙伴欣赏 | 三块一轮，没有标准答案 |
| 转圈/收纳 | 道具加旋转/俯身姿态 | 练习逐步增加，三轮学会 |
| 布置 | 持有物件出现在相应位置 | 存储房间、摆放及位置 |
| 入睡 | 原睡眠姿态、画面变暗 | 点晚安或安静时段；不要求消费 |
| 回忆 | 固定主题图、实际文字和日期 | 来源分清想象/游戏/生活 |

动作采用姿态切换和短过渡，不宣称这些静态图集已变为完整逐帧角色影片。材质为现有毛毡角色配柔和纸艺道具，后续可按相同资源名称替换更精细插画，不需更改玩法。

## 阅读性与停止规则

信息用真实文字，不烘焙进图中；装饰图不干扰读屏。控件有文字或可访问名称，支持键盘。系统或应用“减少动态”关闭位移/缩放/旋转和孵化过渡，直接呈现最终结果，仍能完成同样操作。“轻声唱一句”邀请孩子自己哼唱，点按后给出视觉回应；未新增播放音频或语音识别。动作不依靠循环刺激、无限粒子或持续震动。
