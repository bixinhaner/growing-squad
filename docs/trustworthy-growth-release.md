# 成长小队：可信成长记录与舒适交互交付说明

## 交付范围

本轮在现有 React / Vite / v7 状态与 SQLite 服务上实现改造，不重做系统、不新增外部 AI 上传，不修改生产家庭数据。实现通过分支 `feat/trustworthy-growth-comfort` 和 PR #1 交付；是否合并与部署是独立操作。

| 原审查问题 | 实现与验收位置 |
| --- | --- |
| 首页缺少完成入口、选项只显示第一个 | `ComfortPages.jsx` 展示按状态变化的主卡；`todayEngine.js` 与 `platformReducer.js` 管理开始、完成、暂缓、跳过。`reviewRegression.test.js` 和 `trustworthy-growth.spec.js` 验证刷新与完整闭环。 |
| 早晨和下午状态串用 | `todayDecisions.js` 和 `operationSchemas.js` 使用孩子＋日期＋流程标识；兼容可归属的旧日级记录，不推断不明归属。 |
| 固定的个人成就与空数据造假 | `activitySelectors.js` 统一来源；世界、背包、家长成长页只展示真实记录与诚实空状态。 |
| 姐妹共同活动漏计或重复 | 依据 `participants` 查询；个人角色完成时间单独保存；共同纪念只生成一次。单元与真实浏览器双孩子流程都覆盖。 |
| 没点求助被当成独立 | `scaffoldEngine.js` 只接受明确家长观察；`SupportPage.jsx` 提供可选观察及求助回应；没有证据保持未知。 |
| 运动旧反馈覆盖新反馈 | `movementFeedback.js` 按反馈时间取最近记录；`movementStats` 不把儿童页面点击当作主动提议。 |
| 阅读只有选择、没有表达留存 | 阅读支持可选笔记与出处，背包、成长和阅读家长页可以回看；反馈可直接跳过，不要求交作业。 |
| 发明模板全部套用洗头机器人 | `inventorTemplates.js` 分别配置问题、测试发现、修改与知识卡；自定义项目使用通用探索模板；原有媒体能力继续使用。 |
| 前端紧凑、控制易漏点 | `comfort.css` / `comfort-polish.css` / `comfort-controls.css` 统一布局、触控区域、焦点与响应式行为；手机允许滚动。 |
| 首次设置后导航与保存竞态 | 设置页等待状态安全更新再跳转，测试等待真实页面挂载与持久化完成；刷新和直接进入家长页面仍要求 PIN。 |
| 短间隔创建记录撞号 | 书籍、运动会话、日间自定义项和家庭流程使用独立随机编号，不拿时钟作唯一标识。 |

## 数据与兼容

沿用 v7，不重置现有家庭、孩子、睡前记录和星光账本。新增的日间流程键、个人角色完成时间、阅读笔记出处及家长观察属于可选字段。旧记录没有的信息不补造；已有记录的编号保持不变。

`core.support.evidence-recorded` 和 `core.support.resolved` 是家长操作，不在儿童操作白名单中。共享活动的观察以孩子与能力键分别保存。家长确认之前，建议不会自动改变支持层级；增加帮助不记作退步。

阅读原话只有用户明确选择出处为孩子时才标为“孩子原话”。未指定出处的笔记保持普通笔记；新增书籍只保存元信息，不要求上传正文。

## UI 与交互约定

保留已有角色和毛毡插画。儿童端减少同时出现的决定数量，主操作根据当前状态变化；完成后收尾，不立即催促下一件。没有成长记录时展示等待开始的空状态，不用示例成就冒充历史。

阅读添加弹窗复用应用的焦点管理，支持 Escape 和返回触发按钮。运动、阅读、发明和一问一答中的按钮设置不小于 44px 的宽度及 48px 的高度；无需为适配小屏而缩小文字。目标平板上的 16 项睡前流程保持既有一屏验收，窄屏和大字模式允许自然滚动。

截图只来自实际渲染的页面。完整结果、执行提交、测试数量和截图索引记录在 PR 最终验收评论及对应 GitHub Actions artifacts 中。不要把历史运行的“通过”套用于后续修改。

## 离线构建与缓存边界

生产构建在 Vite 后生成 `precache-manifest.json`，包括按需加载的页面脚本、样式和全部构建内视觉资产；服务工作线程的缓存版本由内容摘要生成。这样无需先在线访问每一个模块，断网后才能打开。安装会等待所有清单资源写入成功，避免只缓存入口脚本造成偶发白屏。

API、带认证头的请求和音视频 Range 请求不进入应用壳缓存；缓存清理只处理成长小队自己的版本，不影响同源的其他应用。生产测试覆盖断网重载及断网后首次进入成长、阅读和发明页面。

## 发布与边界

部署前对已有家庭做可恢复备份；沿用仓库 `deploy/` 的同源子路径与服务配置。没有在本轮连接或操作生产家庭账户，也没有自动部署。

本轮阅读是实体书的陪伴与表达记录，不是电子书、自动分句录音或 AI 评分产品。发明中的图片为引导示意，不是孩子实际作品；真实附件仍需用户主动添加。支持建议是规则辅助和可撤回的家长选择，不是儿童能力诊断。视口检查使用 Chromium，不声称已完成每一台实体设备或 Safari 的验证。
